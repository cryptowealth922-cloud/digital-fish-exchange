# بورصة السمك | Digital Fish Exchange

واجهة عربية متجاوبة لسوق رقمي لتجارة السمك بالجملة.

## ما تتضمنه النسخة
- مساران واضحان: المزاد التصاعدي لعرض الشحنات، والمزاد العكسي لنشر طلبات الشراء.
- تصنيف حسب الصيد الطبيعي والاستزراع السمكي والسمك المستورد.
- شرح الخطوات، مواصفات الشحنة والنقل، والأسئلة الشائعة.
- توضيح أن الإطلاق التجريبي مجاني، وأن عمولة 6% سياسة مستقبلية مقترحة وغير مفعلة.
- نموذج تفاعلي تجريبي لا يرسل البيانات ولا يحفظها على خادم.

## النشر عبر GitHub Pages
1. افتح Settings في المستودع.
2. اختر Pages.
3. في Build and deployment اختر Deploy from a branch.
4. اختر الفرع main والمجلد /(root)، ثم Save.
5. انتظر ظهور رابط الموقع في إعدادات Pages.

## حدود النسخة الحالية
هذه نسخة واجهة أولية ثابتة، وليست منصة معاملات مكتملة. لا توجد حسابات حقيقية أو OTP أو قاعدة بيانات أو مزايدات محفوظة ومتزامنة أو مراسلات أو دفع إلكتروني أو تحصيل عمولة. يلزم بناء خادم وقاعدة بيانات ومصادقة وصلاحيات واختبارات أمان قبل استقبال معاملات حقيقية.
